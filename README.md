# Thaha Wafiq Adly | Web Developer Portfolio 🚀

Selamat datang di repositori kode sumber (*source code*) portofolio profesional saya. Proyek ini dibangun sebagai demonstrasi keterampilan *Frontend Engineering* tingkat lanjut, memadukan **Editorial Flat Design** yang minimalis dengan interaksi modern (PWA, animasi tersinkronisasi, dan desain ultra-responsif).

Sebagai lulusan Ilmu Komputer Universitas Lambung Mangkurat (ULM) dengan pengalaman magang di Hacktiv8 dan BPPKS, saya merancang web ini tidak hanya sebagai pajangan visual, tetapi sebagai bukti pemahaman saya terhadap *Clean Code*, performa, dan pengalaman pengguna (UX).

---

## 🎨 Konsep Desain: Editorial & Flat
Mengambil inspirasi dari majalah digital premium, portofolio ini secara ketat menggunakan *Light Mode* permanen dengan:
- Tipografi besar nan tegas (*Monumental Text*).
- Garis batas tajam dan sudut membulat secara presisi (*Sharp & Rounded borders*).
- *Micro-interactions* (kursor kustom, animasi ledakan *confetti*, dan *toast notifications*).
- Skema warna elegan berbasis monokrom dan aksen *slate/indigo*.

## 🛠️ Tech Stack & Ekosistem
Proyek ini mengimplementasikan teknologi Frontend modern:
- **Core:** React JS 19 + Vite (Super fast HMR & Build)
- **Styling:** Tailwind CSS v4 (Utility-first framework)
- **PWA (Progressive Web App):** Terkonfigurasi untuk dapat diinstal layaknya *native app* di Android/iOS via `vite-plugin-pwa`.
- **Interaksi & UI:** 
  - `sonner` untuk *toast notification* yang menumpuk indah.
  - `canvas-confetti` untuk efek selebrasi.
  - `react-icons` & `react-type-animation`.
- **Form Handling:** Web3Forms API (tanpa server backend terpisah).

## 🌟 Fitur Utama
1. **Interactive Orbit Ecosystem:** Visualisasi teknologi berbasis animasi rotasi konstan yang mulus menggunakan CSS murni.
2. **PWA Ready:** Mendukung instalasi di perangkat seluler dengan *Custom Monogram Favicon*.
3. **Custom Scrollbar & Cursor:** Modifikasi *native cursor* untuk kesan elit dan artistik.
4. **Optimasi Aksesibilitas (A11y):** Skor tinggi di Google Lighthouse (Lazy loading pada gambar dan Aria-labels pada seluruh ikon navigasi).
5. **Modern 404 Page:** Halaman tersesat yang dirancang secara monumental.

## 🚀 Cara Menjalankan Secara Lokal

Pastikan Anda sudah menginstal [Node.js](https://nodejs.org/) di komputer Anda.

1. **Clone repositori:**
   ```bash
   git clone https://github.com/Thahaadly/portfolio-react.git
   cd portfolio-react
   ```

2. **Instal dependensi:**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Jalankan *Development Server*:**
   ```bash
   npm run dev
   ```

4. Buka `http://localhost:5173` di browser Anda.
